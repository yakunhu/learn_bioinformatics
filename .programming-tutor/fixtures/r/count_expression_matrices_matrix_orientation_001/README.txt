Simulated mouse retina bulk RNA-seq count subset for matrix-orientation practice.

retina_counts_annotated.tsv contains:
- one gene per row;
- six raw-count sample columns from control (CTRL) and retinal-degeneration (RD) samples;
- five gene-annotation fields;
- annotation fields deliberately interspersed with sample columns.

The values are simulated and are not suitable for biological claims beyond the assignment.
